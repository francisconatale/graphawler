## Technology Choices

- **Crawlee + Playwright**: Chosen for out-of-the-box request queuing, duplication handling, and network robustness.
- **Mermaid.js**: Chosen for rendering the flow diagram easily via HTML.
- **Zod**: Chosen for runtime configuration validation, ensuring fail-fast behavior if the user provides an invalid `crawler.config.yaml`.
